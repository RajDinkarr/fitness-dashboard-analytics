# 🏋️‍♂️ Interactive Fitness & Gym Analytics Dashboard

A modern, dark-themed Power BI dashboard built to practice advanced UI/UX design, custom theme switching, and interactive calculations.

## 🚀 Key Features & Modules
* **Dynamic Theme Switching:** Custom accent color toggles (Orange, Green, Purple, Blue) for a personalized UI experience.
* **Executive Overview:** High-level summary tracking total clients, trainers, revenue, and expenses.
* **Membership Tier Breakdown:** Visual analysis of Platinum, Gold, and Silver memberships with active vs. expired status tracking.
* **Interactive BMI & Calorie Calculator:** Custom Power BI sliders allowing users to calculate BMI status, maintenance calories, and weight management metrics dynamically.
* **Member Directory:** Searchable member table featuring gender filters and status indicators.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Data modeling, DAX measures, custom UI layout, and bookmarks.
